# GoldCode Events

GoldCode Events is an Aotearoa event brand centered on African music, culture, and community. This glossary keeps the company, its event series, and individual events distinct.

## Language

**GoldCode Events**:
The permanent company and primary website brand.
_Avoid_: GoldCode, Code Code Events, Code Code Defense

**Africa to Aotearoa**:
A recurring GoldCode Events series connecting African music and culture with audiences in Aotearoa.
_Avoid_: Africa Territory, the company

**Event**:
A specific gathering presented by GoldCode Events, with its own name, date, venue, and Event Story. It may also have a Humanitix ticket link.
_Avoid_: Series

**The Link Up – Spring Edition**:
The 24 October 2026 edition of Africa to Aotearoa, held at Vogue Lounge in Auckland.
_Avoid_: Spring Heat, the series, Link Up meeting

**Upcoming Event**:
An announced Event that has not yet taken place and can be promoted through the website.
_Avoid_: Current event

**Past Event**:
An Event that has already taken place. It belongs in the Event Archive and may have an Event Gallery.
_Avoid_: Gallery item

**Featured Event**:
The soonest Upcoming Event. The public ticket action follows this night, and is absent when the night has no Humanitix link.
_Avoid_: Previous Event, a night chosen by hand

**Sold-Out Event**:
An Upcoming Event for which no tickets remain; it stays visible as evidence of demand but no longer presents an active ticket action.
_Avoid_: Past Event, unavailable event

**Event Archive**:
The collection of Past Events shown after Upcoming Events to establish GoldCode Events' history and credibility.
_Avoid_: Gallery

**Event Story**:
The public paragraphs that describe how one Event felt and who played.
_Avoid_: Homepage headline, page title

**Previous Event**:
The most recent Past Event. When that night has no Event Gallery, the next older Past Event that has photographs is used instead.
_Avoid_: Featured Event, the first night

**Event Gallery**:
The photographs that belong to one Event, at most ten, in an order chosen by the Event Manager. Each photograph may have a caption. The photographs may appear on that Event’s own page before the night has happened. The gallery page and the homepage photo block show only a Past Event that has photographs, grouped under that night’s name. A night with no photographs is left off those collections.
_Avoid_: Event Archive, site gallery

**Event Manager**:
The website owner, who creates and updates an Event’s name, date, venue, Event Story, Humanitix link, and Event Gallery from the private administration area.
_Avoid_: User, customer, visitor

**Event Status**:
The public availability state of an Event: Coming Soon, Tickets Available, Low Availability, Sold Out, Postponed, or Cancelled.
_Avoid_: Publish state

**Publish State**:
The private editorial state of an Event: Draft or Published. A Draft is visible only to the Event Manager. Saving a Published Event updates the public site immediately.
_Avoid_: Event Status

**GoldCode Community**:
The primary audience: African diaspora attendees in Aotearoa, alongside everyone interested in Afrobeats, Amapiano, African music, and culture.
_Avoid_: Customers, users
